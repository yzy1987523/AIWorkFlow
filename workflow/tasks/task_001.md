## 1. 任务描述

### 1.1 功能概述
实现用户登录的核心逻辑，包括用户名密码验证、Token生成、登录失败锁定等功能。

### 1.2 详细需求
1. 支持用户名密码登录
2. 验证通过后生成JWT Token
3. Token有效期默认1小时
4. 连续失败5次锁定账户30分钟
5. 记录登录日志
