# 项目启动流程

> 定义如何从零开始初始化一个新项目

## 启动流程概览

```
产品输入需求
      │
      ↓
┌──────────────────┐
│ 初始化项目空间    │
└────────┬─────────┘
         │
         ↓
┌──────────────────┐
│ 需求分析         │ ← 产品Agent
└────────┬─────────┘
         │
         ↓
┌──────────────────┐
│ 架构设计         │ ← 架构Agent
└────────┬─────────┘
         │
         ↓
┌──────────────────┐
│ 生成初始任务     │
└────────┬─────────┘
         │
         ↓
┌──────────────────┐
│ 启动主Agent循环  │
└────────┬─────────┘
```

## 详细步骤

### 1. 产品输入需求

```markdown
# 项目需求

## 项目名称
[项目名称]

## 项目目标
[简要描述项目要解决的问题]

## 核心功能
1. [功能1]
2. [功能2]

## 约束条件
- [技术约束]
- [时间约束]
```

### 2. 需求分析阶段（产品Agent）

```
产品Agent接收原始需求
           │
           ↓
    反向提问（至少3轮）
           │
           ↓
    边界用例挖掘
           │
           ↓
    输出 requirements.md
           │
           ↓
    定义 business_rules.yaml
           │
           ↓
    交付给架构Agent
```

### 3. 架构设计阶段（架构Agent）

```
架构Agent接收需求
           │
           ↓
    模块划分
           │
           ↓
    接口设计
           │
           ↓
    依赖分析
           │
           ↓
    存根生成
           │
           ↓
    任务拆解
           │
           ↓
    交付给主Agent
```

## 启动命令

```bash
# 命令行启动
python -m workflow.main_agent --project projects/{项目名称} --config config.yaml
```

## 验证清单

### 启动前检查
- [ ] 项目目录创建
- [ ] 工作流文件复制
- [ ] 依赖配置
- [ ] 权限配置

### 启动后验证
- [ ] 主Agent心跳正常
- [ ] tasks.json 加载正常
- [ ] contract.json 格式正确
- [ ] 子Agent可启动
